# อภิธานศัพท์ (Glossary)

คำที่ใช้ในเอกสารแผนและโค้ดของเว็บนี้ ให้เรียกตรงกันทุกที่

| คำ | ความหมาย |
|---|---|
| **บท (chapter)** | เนื้อหาจาก PDF 1 ไฟล์ = 1 หน้าเว็บใน `chapters/` มีรหัส `NN-slug` เช่น `01-bmc` |
| **สรุปแก่น (summary)** | ส่วนบนของหน้าบท: นิยาม รายการ ตัวเลข ตาราง จากสไลด์ |
| **หัวข้อย่อย (section)** | `<section>` ในสรุป มี `id` และหัว `<h2>` สารบัญสร้างจากหัวเหล่านี้อัตโนมัติ |
| **จุดที่น่าออกสอบ (exam points)** | กล่องสรุปสั้นท้ายสรุปแก่น |
| **ชุดข้อสอบ (quiz)** | ข้อสอบ 10 ข้อของบท ข้อมูลอยู่ใน `window.QUIZ` |
| **ข้อ (question)** | 1 คำถาม: `q`, `choices` (4 ตัว), `answer` (index เริ่ม 0), `explain`, `ref` |
| **อ้างอิงสไลด์ (ref)** | เลขสไลด์ใน PDF ต้นทางที่เป็นที่มาของคำตอบ |
| **คะแนนสูงสุด (best score)** | คะแนนดีที่สุดของบท เก็บใน localStorage คีย์ `modern-best-<chapterId>` |
| **บทต้นแบบ (prototype chapter)** | บทที่ 1 (BMC) ทำก่อนเพื่อให้ผู้ใช้ตรวจดีไซน์ก่อนทำบทอื่น |
