# ADR 0001: เว็บแบบหลายหน้า HTML/CSS/JS ล้วน เปิดจากไฟล์ได้

- สถานะ: ยอมรับ (2026-10-22)

## บริบท
ผู้ใช้ต้องการเว็บอ่านเตรียมสอบ 10 บท ใช้เฉพาะ HTML, CSS, JS และอยากให้ทำทีละบท

## การตัดสินใจ
- ใช้ **หลายหน้า**: `index.html` + 1 ไฟล์ต่อบทใน `chapters/` ใช้ `css/style.css` และ `js/quiz.js` ร่วมกัน
- ข้อมูลข้อสอบ **ฝังไว้ในแต่ละหน้าบท** เป็น `<script>` ที่กำหนด `window.QUIZ` — ไม่โหลด JSON ด้วย `fetch` เพราะเบราว์เซอร์บล็อก `fetch` ของไฟล์ในเครื่อง (`file://`)
- ฟอนต์: Google Font (Sarabun) พร้อมฟอนต์สำรองของระบบ ออฟไลน์ก็ยังอ่านได้
- ไม่ใช้ framework หรือ build step

## ผลที่ตามมา
- เพิ่มบทใหม่ได้โดยไม่แตะบทเก่า (แค่เพิ่มไฟล์และเปิดการ์ดใน index)
- เนื้อหาซ้ำ (header/footer) ต้องคัดลอกทุกหน้า — ยอมรับได้เพราะมีแค่ 11 หน้า
