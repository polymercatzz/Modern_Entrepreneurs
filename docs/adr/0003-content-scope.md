# ADR 0003: ขอบเขตเนื้อหาสรุป

- สถานะ: ยอมรับ (2026-10-22)

## การตัดสินใจ
- สรุประดับ "แก่น + ตาราง": นิยาม รายการข้อ ๆ ตัวเลขสำคัญ ตารางเปรียบเทียบ อ่านจบบทละ 10–15 นาที
- ตัดภาพประกอบ ตัวอย่างข่าว และรายละเอียดที่ไม่น่าออกสอบ
- **บทบัญชี-ภาษี (บทที่ 10) ครอบคลุมเฉพาะ** (ผู้ใช้กำหนด):
  - ภาษีเงินได้บุคคลธรรมดา: เงินได้ 40(1)–40(8) และค่าลดหย่อน
  - ภาษีเงินได้นิติบุคคล: อัตรา SME 0/15/20% และรายจ่ายต้องห้าม 7 ข้อ
  - ไม่รวม VAT, ภาษีหัก ณ ที่จ่าย, SBT, ประกันสังคม, งบการเงิน
- ข้อมูลบนสไลด์ที่น่าจะพิมพ์ผิด ให้ใส่ตามที่ถูกต้องพร้อมหมายเหตุสั้น ๆ (เช่น หัวข้อ Cost/Revenue ที่สลับกันในตัวอย่าง BMC น้ำผลไม้)
- แหล่งเนื้อหา: โน้ตที่ถอดจากสไลด์ทุกหน้า (อ่านจากภาพ เพราะ PDF ไม่มีข้อความภาษาไทยให้ดึง)
